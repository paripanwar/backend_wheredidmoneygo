
# Where Did My Money Go? 💸

A personal expense tracker built with Python, Flask, and SQLite.

## Features
- Add, view, edit, and delete expenses
- Organize expenses by category
- Calculate monthly spending
- View category-wise spending breakdowns
- Set a monthly budget
- Create savings goals

## Technologies Used
- Python
- Flask
- SQLite
- Flask-CORS
- REST API

## Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the server:

```bash
python app.py
```

Open http://127.0.0.1:5000 to check the API.

## Expense Categories
Food, Shopping, Travel, Entertainment,
Education, Bills, Health, and Other.

## Note
This is a learning and portfolio project.
It does not include user authentication.
